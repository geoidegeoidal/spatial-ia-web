01. Syllabus_

S01

Fundamentos de IA y Spec-Driven Development

  • > ¿Qué es un LLM y cómo programar asistido por IA usando Antigravity IDE y OpenCode?

    Entenderemos la arquitectura detrás de los grandes modelos de lenguaje y cómo interactuar con ellos gratuitamente desde el editor, transformando texto natural en estructura de proyecto de forma guiada.

  • > Ingeniería de Prompts: Spec-Driven Development para código web.

    Aprenderemos la metodología técnica para escribir especificaciones (specs) claras y sin ambigüedades, logrando que la IA actúe como un programador que escribe código web limpio y predecible.

  • > Generación de UI: Del mockup al código con IA.

    Diseñaremos las maquetas de nuestro visor territorial y las convertiremos instantáneamente en una interfaz web moderna (HTML/Tailwind) sin tener que tipear CSS manualmente.

S02

Dashboards Territoriales y Web Mapping Reactivo

  • > Ecosistema Open Source: MapLibre GL JS / Leaflet.

    Dominaremos librerías de web mapping de código abierto para renderizar mapas fluidos, liberándonos por completo de licencias costosas y dependencias comerciales.

  • > Ensamblaje ("Stitching"): Integrando diseños generados en stitch.withgoogle.com.

    Conectaremos las interfaces visuales generadas con la lógica de nuestro visor, aprendiendo el flujo para "coser" el mapa interactivo dentro del contenedor diseñado de manera impecable.

  • > Reactividad: Filtros espaciales interactivos.

    Programaremos la comunicación entre el mapa y el dashboard, logrando que clics o controles actualicen dinámicamente datos, popups y visualizaciones.

S03

Análisis Espacial en el Navegador y Despliegue

  • > Geoprocesamiento Client-Side: Cálculos espaciales sin servidores.

    Implementaremos librerías como Turf.js para realizar análisis espaciales (buffers, áreas, uniones) directamente en el navegador del usuario, logrando una arquitectura ligera.

  • > Manejo de Datos: GeoJSON y formatos optimizados.

    Aprenderemos técnicas para optimizar la carga y renderizado de información espacial densa, logrando que nuestros visores respondan de forma ultrarrápida.

  • > A Producción: Despliegue gratuito en GitHub Pages.

    Subiremos nuestro código terminado a la nube. Configurarás tu propio repositorio para obtener un enlace público y seguro (HTTPS) listo para el portafolio, a costo cero.
