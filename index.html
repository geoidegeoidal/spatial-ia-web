Module.01

Arquitectura del Syllabus.

S01 // Viernes 7 >>

Fundamentos de IA y Spec-Driven Development

  • ¿Qué es un LLM y cómo programar asistido por IA? Entenderemos la arquitectura detrás de los grandes modelos de lenguaje y cómo interactuar con ellos gratuitamente.
  • Ingeniería de Prompts y Spec-Driven Development. Aprenderemos la metodología técnica para escribir especificaciones claras y lograr que la IA genere código web.
  • Generación de UI. Diseñaremos las maquetas de nuestro visor y las convertiremos instantáneamente en interfaces modernas con Tailwind.
S02 // Sábado 8 >>

Dashboards Territoriales y Web Mapping Reactivo

  • Ecosistema Open Source: MapLibre / Leaflet. Dominaremos librerías de web mapping para renderizar mapas fluidos sin dependencias comerciales.
  • Ensamblaje ("Stitching"). Conectaremos interfaces visuales con la lógica de nuestro visor interactivo.
  • Reactividad y Filtros. Programaremos la comunicación entre el mapa y el dashboard para actualizar datos dinámicamente.
S03 // Domingo 9 >>

Análisis Espacial en el Navegador y Despliegue

  • Geoprocesamiento Client-Side sin servidores. Implementaremos Turf.js para análisis espaciales (buffers, áreas, uniones) directamente en el navegador web del usuario.
  • Manejo de Datos: GeoJSON optimizados. Aprenderemos técnicas para optimizar la carga y renderizado de información espacial densa.
  • A Producción: GitHub Pages. Subiremos nuestro código terminado a la nube. Obtendrás un enlace público y seguro (HTTPS) a costo cero.
