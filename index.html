Tú defines el qué. La IA ayuda con el cómo.

Trabajaremos con OpenSpec: explorar el problema, proponer un cambio y aplicarlo con criterios de aceptación. Conocerás cómo se organizan proposal.md, specs/, design.md y tasks.md para construir y verificar sin perder el control de tu aplicación.

¿Qué proyecto construiremos?

Partiremos de un visor territorial: una interfaz con mapa, filtros y fichas de información. Después abordaremos gráficos sincronizados, exportación de datos y herramientas de análisis. El objetivo es contar con una base que puedas adaptar a tus propios datos y publicar en la web.

Análisis espacial y visualización: el siguiente nivel
  • Áreas de influencia parametrizadas en metros y disolución, considerando sistemas de coordenadas y geometrías válidas.
  • Procesamiento del conjunto completo o de las entidades filtradas; descarga de resultados como GeoJSON y Shapefile empaquetado en ZIP.
  • Simbología y leyendas generadas desde una fuente común; mapa y gráficos sincronizados con el mismo estado de filtros.
  • Revisión de estados de carga, resultados vacíos y rendimiento sin romper las funcionalidades existentes.

Estos contenidos se abordan mediante ejemplos guiados. La profundidad de implementación dependerá del ritmo del grupo y de la complejidad de los datos; el curso concentra 4,5 horas en vivo.

Publicar, mejorar y seguir aprendiendo

Revisaremos el control de versiones y el despliegue con GitHub CLI y GitHub Pages, la adaptación a móviles y la comparación de variantes de interfaz. Usaremos especificaciones y verificaciones para mejorar la experiencia de uso conservando las funcionalidades del proyecto.

04 / Antes de empezar

Buenas preguntas.

¿Necesito experiencia programando?

El curso está orientado a trasladar el conocimiento territorial a la web con asistencia de IA. Trabajaremos con instrucciones, especificaciones y revisión del código generado. La familiaridad con capas y tablas de atributos SIG te ayudará a aprovechar los ejercicios.

¿Necesito contratar un servidor?

El proyecto del curso utiliza una arquitectura Zero-Server: el mapa y el análisis se ejecutan en el navegador, y los archivos se publican en un alojamiento estático como GitHub Pages. Los servicios externos de IA, mapas base y alojamiento tienen sus propias condiciones y límites de uso.
